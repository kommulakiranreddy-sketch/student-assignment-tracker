# Student Assignment Tracker

## Team Member

- Kiran Reddy Kommula

## Project Abstract

The Student Assignment Tracker is a web application designed to help college students organize and manage their coursework. Users will be able to add assignments, enter course names and due dates, set priorities, and mark assignments as completed. The application will also allow users to edit, delete, search, and filter their assignments. This project is intended for students who need a simple and convenient way to manage their academic workload and avoid missing important deadlines.
