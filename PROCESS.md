## Selected Process Model

Scrum adapted for an individual project

## Why I Selected Scrum

I selected Scrum because it allows me to divide the Student Assignment Tracker into smaller features and complete them in short development cycles. The project has separate functions, such as adding, viewing, editing, deleting, searching, filtering, setting priorities, and marking assignments complete. Using a backlog helps me decide which feature to work on first and keeps the project organized.

Because I am developing the project by myself, I will perform the planning, development, testing, and review activities personally. I will use the project board to track my progress and review my work at the end of each sprint.

## Project Board

https://github.com/users/kommulakiranreddy-sketch/projects/1

## Work Tracking

All planned features are placed in the Backlog column. When I begin working on a feature, I move it to In Progress. After the feature meets its acceptance criteria and I test it, I move it to Done.

## Backlog Items

- Add an assignment
- View assignments
- Set assignment priority
- Mark an assignment complete
- Edit an assignment
- Delete an assignment
- Search assignments
- Filter assignments

## Sprint 1

- Length: One week
- Goal: Create the basic assignment tracking functions.
- Selected items:
  - Add an assignment
  - View assignments
  - Mark an assignment complete

During the sprint, I will check my progress regularly, test each completed feature, and record any problems that need additional work.

## Completion Checks

A feature can move to Done when it works as expected, satisfies its acceptance criteria, handles invalid input appropriately, and has been tested by me.

## Review and Improvement

At the end of each sprint, I will review the completed features, identify problems, and update the backlog. I will use the review to decide what should be changed or prioritized in the next sprint.
